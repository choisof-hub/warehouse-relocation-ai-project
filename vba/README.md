# VBA Tools

このフォルダには、倉庫移転に伴う棚番変更作業を支援するために作成したVBAツールを格納しています。

---

## create_conversion_table.bas

### 概要

旧棚番配置図と新棚番配置図を比較し、新旧棚番変換表を自動生成するツールです。

### 主な機能

* 旧棚番配置図を走査
* 同一セル位置の新棚番を取得
* 新旧棚番変換表を自動生成
* 未設定棚番は「■■■」として出力
* 棚番を文字列として扱い、Excelの指数変換を防止

### 活用効果

倉庫レイアウト変更時でも、配置図を修正するだけで最新の新旧棚番変換表を再生成できるようになりました。

---

## create_update_file.bas

### 概要

新旧棚番変換表を利用し、既存の棚番マスタから更新用Excelファイルを作成するツールです。

### 主な機能

* 新旧棚番変換表を辞書(Dictionary)として読み込み
* 棚番マスタ内の旧棚番を新棚番へ変換
* 約19,000件のデータを一括処理
* 未定義棚番の自動検出
* 進捗率表示
* 更新用Excelファイル作成

### 技術的な工夫

* Scripting.Dictionaryを利用した高速変換
* ヘッダー名による列自動認識
* 配列処理による高速化
* ステータスバーによる進捗表示
* エラー処理および入力チェックの実装

### 活用効果

移転計画の変更に伴い変換表が修正された場合でも、最新の更新用Excelファイルを短時間で再生成できるようになりました。

---

## プロジェクトにおける位置付け

本プロジェクトでは、

1. 旧棚番配置図・新棚番配置図の作成
2. 新旧棚番変換表の生成
3. 更新用Excelファイルの作成
4. システム部門による棚番一括更新

という流れで倉庫移転に対応しました。

本フォルダのVBAは、新旧棚番変換表の生成と更新用Excelファイルの作成を支援するために作成したツールです。
